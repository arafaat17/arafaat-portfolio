# Arafaat Shaikh — portfolio

A small static portfolio for applied AI and automation engineering. No build step or tracking scripts are required.

## Preview

Run `python3 -m http.server 8000` and open `http://localhost:8000`.

## Publish

This repository is connected to Vercel. Pushing to `main` should create a production deployment in the connected Vercel project. The current public URL is <https://arafaat-portfolio-psi.vercel.app/>.

## Content

Public projects link to their source. Private work is described in anonymized, high-level terms. Replace the contact email and canonical/Open Graph URL after setting up a custom domain.
