ANONYMISED CASE STUDY / CUSTOMER OPERATIONS

Bring voice and chat context into the customer workflow.

Customer context arrives through CRM events, chat transcripts, and voice attachments. The engineering challenge is coordinating that work and returning a validated summary to the tools people already use.

My contribution
Designed an event-driven ingestion and synthesis pipeline, including asynchronous processing, validated LLM summarisation, reconciliation, and audit visibility.

GCP · Python · Gemini · AssemblyAI · BigQuery
Receive & decouple CRM webhook → gateway → Pub/Sub
Queue & track Cloud Tasks + Firestore lifecycle state
Transcribe & synthesise Voice transcription + validated LLM output
Return & observe CRM write-back + BigQuery audit trail
Reconcile Scheduled checks for stale events
The decision

Separate receiving from processing.

Decoupling webhook ingestion from transcription and synthesis lets the work move through an asynchronous pipeline.

The reliability work

Account for unfinished work.

Lifecycle state, audit logging, and scheduled reconciliation make stale events visible and support recovery.

The resulting capability

Validated context in existing tools.

The pipeline returns synthesised customer context to enterprise tools, with an audit trail for investigation.
